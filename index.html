Ray Marching Lava Lamp

Личный R&D проект • Solo Developer Personal R&D • Solo Developer

Процедурный рендерер объемной графики на базе Unity URP и конвейера RenderGraph. Сцена строится методом Ray Marching по полям расстояний (SDF) без полигональных 3D-мешей, симулируя динамическое органическое слияние частиц (эффект лава-лампы). Включает оптимизацию прохода лучей через габаритный контейнер (Ray-AABB), расчет нормалей и кастомную HLSL-модель освещения (Main Light, Rim, Glow). Real-time procedural volumetric renderer built on Unity URP and the RenderGraph pipeline. Uses Signed Distance Field (SDF) Ray Marching to render dynamic organic fluid shapes (lava lamp effect) without polygonal 3D meshes. Features Ray-AABB bounding box acceleration, analytical normal reconstruction, and a custom HLSL lighting model (Main Light, Rim, Glow).

Unity C# Shaders / HLSL URP
