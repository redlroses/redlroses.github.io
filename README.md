# Evgeny Batenkov — Engineering Portfolio & Architecture Case Studies

Личная страница инженерных достижений, архитектурных кейсов и портфолио в сфере **Unity / XR & Software Engineering**.

## 🌟 Ключевые особенности
- **Формат инженерных кейсов (Staff / Senior Case Studies):** детальный разбор ключевых систем (контекст, архитектурные решения, преодоление инженерных вызовов, результаты и метрики).
- **Двуязычность (RU / EN):** мгновенное переключение языка прямо в шапке с сохранением выбора в `localStorage` (русская и английская версии согласованы на 100%).
- **Деловой технологичный стиль:** строгая типографика (*Syne*, *Manrope*, *DM Mono*), палитра темного обсидиана, отсутствие вычурных анимаций и эмодзи-перегрузки.
- **Тёмная и светлая тема:** поддержка системных настроек ОС и ручной тумблер.
- **Чистый стек:** Vanilla HTML5 + CSS3 + JS, 0 зависимостей, мгновенная загрузка.

---

## 🚀 Как запустить локально

Откройте `index.html` двойным кликом в браузере, либо запустите локальный сервер:
```bash
python -m http.server 8000
```
И перейдите по адресу: `http://localhost:8000`.

## 🌐 Публикация на GitHub Pages

Репозиторий готов к развертыванию на `github.com/redlroses`:

1. Создайте репозиторий с именем **`redlroses.github.io`** на GitHub.
2. В терминале папки проекта выполните:
   ```bash
   git init
   git add .
   git commit -m "feat: engineering portfolio case studies and achievements"
   git branch -M main
   git remote add origin https://github.com/redlroses/redlroses.github.io.git
   git push -u origin main
   ```
3. Сайт станет доступен по постоянному адресу:
   👉 **`https://redlroses.github.io/`**

## 📄 Файлы проекта:
- `index.html` — семантическая двуязычная разметка с кейсами и матрицей компетенций.
- `style.css` — стили, адаптив, типографика, оформление тем и переключения языков.
- `script.js` — контроллеры переключения тем и языков.
- `RESUME_RU.md` — отдельный документ с текстом резюме для hh.ru (не связан со страницей).
- `.gitignore` — защита токенов и конфиденциальных файлов от коммита.
